# Security

The package reads local view/fold information. It performs no network requests,
collects no analytics and stores no credentials.

Report sensitive vulnerabilities privately through GitHub's private vulnerability
reporting when enabled. If it is unavailable, open an issue requesting a private
contact without disclosing exploit details or private data. Ordinary bugs can use
public issues. During 0.x, fixes target the latest release; there is no long-term
support promise for older versions.
